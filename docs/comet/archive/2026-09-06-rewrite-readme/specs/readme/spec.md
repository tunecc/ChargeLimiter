# Capability: README 项目说明文档

仓库根目录提供一份 `README.md`（自 `Readme.md` 重命名），作为 ChargeLimiter 本 fork 的权威项目说明，面向新用户与既有用户，GitHub 直接渲染。全文为中英双语：前半部分为简体中文，后半部分为 English，两部分章节一一对应、事实一致；文首放置互相跳转的语言锚点链接。

## 1. 文档结构（中文部分；English 部分逐节对应）

1. **标题与一句话定位**：ChargeLimiter（CL）——面向 iPhone 的充电控制工具（AlDente 替代），用于减少长时间高电量、高温与长期满充对电池健康度的损害。
2. **重要声明**：它不是硬件级旁路充电；当前实现为软件层策略控制（电量、温度、供电状态、系统优化充电状态与守护进程策略共同决定停充/恢复/禁流/限流）。沿用上游口径保留免责条款（永久免费无广告；软硬件环境不兼容不建议使用；使用即默认同意免责条款，措辞按本 fork 调整）。
3. **截图**：引用仓库内 `screenshots/` 现有图片（相对路径），以 `<p align="center">` 横排展示。
4. **当前定位 / 适用环境**：
   - 本质是充电策略调度器，不是硬件电源路径改造器；列出它决定的五类行为（是否充电、停充、禁流、协调系统优化充电、满充窗口放开上限）。
   - 支持 TrollStore / 越狱 rootful / rootless / roothide（`Package_roothide` 原生构建）；最低 iOS 13.0；标注经过开发验证的重点环境（iOS 15–17，relaxin/roothide 原生适配自 v1.15.0）。
5. **功能总览**（以 CHANGELOG v1.15.x 与源码为准）：电量上限/下限控制、智能停充（`PredictiveChargingInhibit` 优先、自动回退传统路径）、停止电量=100% 时交由系统控制、停充时启用禁流、温度控制、系统优化充电协调与永久停用、满充计划、限流等级（原子配置）、高温模拟 Powercuff、加速充电、策略诊断、历史统计、策略事件时间线、导出（诊断摘要/事件时间线/长测校准模板）、日志级别（标准/仅错误）、悬浮窗、插电即充/边缘触发模式。
6. **适合谁 / 不适合谁**：长期插电、整夜充电、关注温度与健康度的用户；硬件不支持停充且不支持禁流的设备不适用。
7. **使用前必看**（吸收上游，校订至本 fork）：iPhone 8+ 存在至多 120 秒的充电状态设定延迟；停充模式不更新系统状态栏充电标志、禁流模式会更新；TrollStore 环境服务被杀（重启/用户空间重启/iCloud 同步强杀等）会失效并表现为一夜充满，CL 提供尽力而为的保活（scheme/悬浮窗拉起）；系统自带"优化电池充电"与本工具的关系（本 fork 提供协调与永久停用能力，说明各选项语义）；新电池先激活再使用；长期停充建议每月至少满充满放一次。
8. **新用户学习资料**（吸收上游权威内容，按本 fork 校订）：
   - **停充 / 禁流 / 限流名词解释**（上游定义原文保留，注明三者优先场景）。
   - **电池兼容性测试**：三步测试法（关全局开关手动控制"正在充电"按钮测停充；开智能停充再测；"电源已连接"按钮测禁流），120 秒内无反应或停充后持续电流 ≥5mA（以实际电量变化为准）即硬件不支持；低健康度/高温/未激活电池的失控表现；既不支持停充也不支持禁流则不适用。
   - **品牌新电池激活方法**：上游整理的常见品牌激活方法（诺希、Dseven、德赛、欣旺达、ART、ZASZ、品胜、长和胜、飞毛腿、中正、曲赛德）整段保留；注明以电池厂商官方说明为准。
   - **充电宝兼容性**：停充模式下充电宝优先供电的意义；无线充电不推荐；有线充电宝"休眠模式"的坑与"小电流模式"的用法。
   - **常见问题 FAQ**（上游整组保留并校订）：什么情况下需要用 CL；CL 更费电吗；支持第三方电池吗；使用后健康度会增加吗（含"停充且连电源理想电流为 0"的说明）；为什么无法停充/恢复充电（小白高频问题全列表：温控阈值设置、设计思路是减少充电次数、低健康度电池失效、过热硬件停充失效、新电池未激活、iPad pd charger 换线、巨魔环境服务被杀）；没有越狱/巨魔能否安装；夏天怎样降低电池温度；怎样使用电池最好（Apple 官方链接）；遇到问题如何自行诊断（5 分钟图 + `aldente.log` 数据缺失）；如何找到耗电应用。
   - **阈值设定说明**：默认阈值与需要按实际情况调整的原则；设定值与实际触发值存在偏差的原因（120 秒延迟、充电速度、电池质量、0–1% 常见 / 极少数 3–5%）；iPad 长期连电的"最佳停充电量"确定方法；温度阈值结合"历史统计-小时"数据设定。
9. **使用说明**（以本 fork 实际界面为准）：
   - **全局开关**：关闭后进入观察者模式，只读不改。
   - **主页面**：停止充电（电量 ≥）主滑块与停充预设、供电状态/充电命令/系统停充抑制/系统优化充电状态、适配器功率电压、电池健康/温度/电流/电压/循环次数；插电与未插电时的呈现侧重。
   - **充电高级**：智能停充（含回退机制）；停止电量=100% 交由系统控制（与普通上限场景的区别）；停充时启用禁流（更激进，负载由电池承担，适用与风险）；系统优化充电（临时协调会话：记录原始状态、会话 ID、重启后再判断、外部变更时结束会话；永久停用选项）；满充计划（每隔天数/开始时间/持续时长，窗口内放开上限、温控仍生效）；限流等级（通过热状态模拟让系统整体更保守，非直接对 PMIC 下发电流；关闭/正常/轻度/中度/重度）；高温模拟 Powercuff（默认热状态模拟、锁定等级）；加速充电（降低设备功耗而非提高充电器功率：飞行模式/Wi-Fi/蓝牙/降低亮度/低电量模式，适合临时补电）。
   - **模式**：插电即充（随用随充）与边缘触发（常年连电）的触发条件与优先级（吸收上游表述）。
   - **悬浮窗**：实时状态与服务存活指示、可拖动、点击切换全局开关、自动隐藏。
   - **策略诊断 / 历史统计 / 策略事件时间线 / 导出**：诊断字段清单（守护策略、状态原因、充电命令、系统停充抑制、协调会话等）；5 分钟/小时/天/月曲线与可查看指标；事件时间线独立持久化、重启保留、删除联动；导出三项能力。
   - **软件设置**：日志级别（标准/仅错误，只过滤 `aldente.log` 文件输出）；更新频率（若 fork 保留该项则写，否则省略）。
   - **排障建议**：先看策略诊断 → 实时信号 → 供电环境 → 再调参数的顺序；长期验证配合 `docs/真机长测与阈值校准.md`。
10. **快捷指令**：`cl://` URL 列表（按本 fork 实际支持的路径），配自动化实现指定电量充停与保活拉起的用法与限制（非锁屏生效、120 秒延迟）。
11. **HTTP API 参考**：绑定 `127.0.0.1:1230`；`get_conf` / `set_conf` / `get_bat_info` / `set_charge_status` / `set_inflow_status` / `set_limit_inflow_config` / `get_diag` / `get_policy_events` / `apply_now` 等 api 端点，请求/响应结构与上游同风格表格；全局配置键表格逐键与 `daemon.mm` 实现一致（含 fork 新增：满充计划 `full_charge_sched_*`、hold 行为键、`acc_charge_bright_auto` 等；标注只读键如 `thermal_simulate_mode`、`use_smart`）；附 curl 示例。
